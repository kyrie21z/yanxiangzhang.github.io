这是我在游戏开发课程中围绕**多智能体世界游戏（Multi-Agent World Games）**整理的一份调研简报，完整内容以独立交互页面的形式放在站内：

[打开交互简报：AI 驱动游戏与多智能体世界](/ai-driven-games-research/)

## 简报涵盖内容

页面系统梳理了从学术原型到商业游戏落地的脉络与工程取舍：

1. **斯坦福生成式智能体（Smallville）**：拆解记忆流（Memory Stream）、检索评分、反思与规划循环，以及消融实验与 API 成本局限。
2. **Google DeepMind Concordia**：介绍 Game Master（GM）架构，并与 Smallville 做机制对比。
3. **标志性多智能体世界项目**：包括千级智能体的 **Project Sid**（Minecraft）与具身智能体 **Voyager** 等代表工作。
4. **商业游戏中的 AI NPC**：整理 NVIDIA ACE、Inworld / 育碧 Neo NPCs 与 Latitude Voyage 等实践。
5. **学生开发者核心技术**：涵盖智能体架构、多智能体通信、成本与延迟控制、游戏引擎接入及涌现行为评估。
6. **课程实用入门路径**：围绕 3–8 个智能体 + 本地推理（Ollama）的零 API 账单路线，比较了 a16z AI Town、Concordia、LLMUnity 与 Minecraft 方案，并给出三个限定范围的课程项目构想。
