# Source Code

```python
def sort(arr):
    """
    插入排序
    
    Args:
        arr: 待排序列表
        
    Returns:
        排序后的列表
    """
    # 创建副本，避免修改原列表
    result = list(arr)
    
    for i in range(1, len(result)):
        key = result[i]
        j = i - 1
        
        # 将大于key的元素向后移动
        while j >= 0 and result[j] > key:
            result[j + 1] = result[j]
            j -= 1
        
        result[j + 1] = key
    
    return result

```
