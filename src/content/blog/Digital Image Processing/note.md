# week 1
## neighborhood (邻域)
定义:一个像素的邻域是指以该像素为中心的一定范围内的像素集合。邻域的大小和形状可以根据需要进行调整。
示例:在一个3x3的邻域中,中心像素的邻域包括周围的8个像素。
1. 4邻域:包括中心像素的上下左右四个像素。
2. 8邻域:包括中心像素的上下左右四个像素以及四个对角线像素。
## connectivity (连通性)
定义:在图像处理中,连通性是指像素之间的连接关系。常见的连通性有4连通和8连通。
示例:在一个4连通的图像中,一个像素与其上下左右四个像素相连;在一个8连通的图像中,一个像素与其上下左右四个像素以及四个对角线像素相连。
1. 4连通:一个像素与其上下左右四个像素相连。
2. 8连通:一个像素与其上下左右四个像素以及四个对角线像素相连。
## distance measures（距离度量）
定义:距离度量是用来衡量像素之间的距离或相似性的函数。常见的距离度量有欧氏距离、曼哈顿距离和切比雪夫距离。
1. 欧氏距离:两个像素之间的欧氏距离是它们在空间中的直线距离。计算公式为: d = sqrt((x2 - x1)^2 + (y2 - y1)^2)
2. 曼哈顿距离:两个像素之间的曼哈顿距离是它们在空间中的绝对距离。计算公式为: d = |x2 - x1| + |y2 - y1|
3. 切比雪夫距离:两个像素之间的切比雪夫距离是它们在空间中的最大距离。计算公式为: d = max(|x2 - x1|, |y2 - y1|)

# week 2
## 算子
### 线性算子
定义:满足叠加原理的算子
叠加原理:对于任意的输入图像f1和f2,以及任意的标量a和b,线性算子L满足以下条件:
L(a*f1 + b*f2) = a*L(f1) + b*L(f2)
示例:卷积算子是一个线性算子,因为它满足叠加原理。   
### 非线性算子
定义:不满足叠加原理的算子
示例:中值滤波器是一个非线性算子,因为它不满足叠加原理。
## arithmetic operations（代数运算）
1. 加法:将两幅图像的像素值相加,得到一幅新的图像。
2. 减法:将两幅图像的像素值相减,得到一幅新的图像。
3. 乘法:将两幅图像的像素值相乘,得到一幅新的图像。
4. 除法:将两幅图像的像素值相除,得到一幅新的图像。
## logic operations（逻辑运算）
1. 与运算:对于两幅二值图像,如果对应像素值都为1,则结果像素值为1;否则,结果像素值为0。
2. 或运算:对于两幅二值图像,如果对应像素值至少有一个为1,则结果像素值为1;否则,结果像素值为0。
3. 非运算:对于一幅二值图像,如果像素值为1,则结果像素值为0;如果像素值为0,则结果像素值为1。
4. 异或运算:对于两幅二值图像,如果对应像素值不同,则结果像素值为1;否则,结果像素值为0。
## single pixel operations（单像素运算）
1. 灰度反转:将图像的每个像素值进行反转,即将像素值v变为255-v。
2. 对数变换:将图像的每个像素值进行对数变换,即将像素值v变为c*log(1+v),其中c是一个常数。
3. 伽马变换:将图像的每个像素值进行伽马变换,即将像素值v变为c*(v^gamma),其中c是一个常数,gamma是一个参数。
4. 线性变换:将图像的每个像素值进行线性变换,即将像素值v变为a*v+b,其中a和b是常数。
## neighborhood operations（邻域运算）
1. 平滑滤波:通过对图像的每个像素值进行邻域内像素值的平均或加权平均,来减少图像中的噪声。
2. 锐化滤波:通过对图像的每个像素值进行邻域内像素值的差分或加权差分,来增强图像中的边缘和细节。
3. 边缘检测:通过对图像的每个像素值进行邻域内像素值的梯度或拉普拉斯算子,来检测图像中的边缘。
4. 形态学操作:通过对图像的每个像素值进行邻域内像素值的最大值或最小值,来进行图像的膨胀或腐蚀。
## Histogram operations（直方图运算）
1. 直方图均衡化:通过对图像的直方图进行均衡化,来增强图像的对比度。
2. 直方图匹配:通过对图像的直方图进行匹配,来使图像的直方图与目标直方图相似。
3. 直方图规范化:通过对图像的直方图进行规范化,来使图像的直方图满足特定的分布。
4. 直方图平滑:通过对图像的直方图进行平滑,来减少图像中的噪声。
### 直方图的定义
直方图是图像中像素值分布的统计图表。它显示了图像中每个像素值出现的频率。直方图通常以像素值为横轴,频率为纵轴,来表示图像的亮度分布。
### 直方图的计算
计算直方图的方法是遍历图像中的每个像素值,统计每个像素值出现的次数。可以使用一个数组来存储每个像素值的频率,然后将频率进行归一化,得到每个像素值的概率分布。
## geometric operations（几何运算）
### 刚体变换
定义:刚体变换是指保持图像的形状和大小不变的变换。常见的刚体变换包括平移、旋转和缩放。
#### 平移:
定义：将图像中的每个像素值按照一定的距离进行平移,得到一幅新的图像。
#### 旋转:
定义：将图像中的每个像素值按照一定的角度进行旋转,得到一幅新的图像。

对于一个像素值v在图像中的位置(x,y),经过旋转theta后的新位置(x',y')可以通过以下公式计算: 


$x' = x*\cos(\theta) - y*\sin(\theta)$

$y' = x*\sin(\theta) + y*\cos(\theta)$


矩阵表示:旋转可以通过以下矩阵表示:

```
| cos(theta)  -sin(theta)  0 |
| sin(theta)   cos(theta)  0 |
|     0            0       1 |
```

#### 水平镜像
定义：将图像中的每个像素值按照一定的轴进行镜像,得到一幅新的图像。

对于一个像素值v在图像中的位置(x,y),经过水平镜像后的新位置(x',y')可以通过以下公式计算:

$x' = width - 1 - x$

$y' = y$

## gray level interpolation（灰度插值）
定义:灰度插值是指在图像中根据已知像素值来估计未知像素值的过程。常见的灰度插值方法包括最近邻插值、双线性插值和双三次插值。
### 最近邻插值:
定义:对于一个未知像素位置,选择其周围最近的已知像素值作为估计值。

示例:对于一个未知像素位置(x,y),其周围四个已知像素值分别为f(0,0), f(1,0), f(0,1)和f(1,1),则未知像素值f(x,y)可以通过以下公式计算:


$f(x,y) = f(round(x), round(y))$

### 双线性插值:
定义:对于一个未知像素位置,根据其周围四个已知像素值的加权平均来估计未知像素值。

公式:对于一个未知像素位置(x,y),其周围四个已知像素值分别为f(0,0), f(1,0), f(0,1)和f(1,1),则未知像素值f(x,y)可以通过以下公式计算:

$f(x,y) = f(0,0)*(1-x)*(1-y) + f(1,0)*x*(1-y) + f(0,1)*(1-x)*y + f(1,1)*x*y$

### 双三次插值:
定义:对于一个未知像素位置,根据其周围16个已知像素值的加权平均来估计未知像素值。

公式:对于一个未知像素位置(x,y),其周围16个已知像素值分别为f(-1,-1), f(0,-1), f(1,-1), f(2,-1), f(-1,0), f(0,0), f(1,0), f(2,0), f(-1,1), f(0,1), f(1,1), f(2,1), f(-1,2), f(0,2), f(1,2)和f(2,2),则未知像素值f(x,y)可以通过以下公式计算:


$f(x,y) = sum_{i=-1}^{2} sum_{j=-1}^{2} f(i,j) * w(x-i) * w(y-j)$

### 应用场景
1. 图像缩放:在图像缩放过程中,需要根据已知像素值来估计未知像素值,以得到新的图像。
2. 图像旋转:在图像旋转过程中,需要根据已知像素值来估计未知像素值,以得到新的图像。
3. 图像变形:在图像变形过程中,需要根据已知像素值来估计未知像素值,以得到新的图像。

## 后向映射
定义:后向映射是指在图像中根据目标像素位置来寻找对应的源像素位置的过程。后向映射通常用于图像的几何变换中,如旋转、缩放和平移。
示例:在图像旋转中,对于目标像素位置(x',y'),可以通过以下公式计算对应的源像素位置(x,y):

$x = x'\cos(\theta) + y'\sin(\theta)$

$y = -x'\sin(\theta) + y'\cos(\theta)$

# week 3 空间域图像增强
## Negative transformation（负片变换）
定义:负片变换是指将图像的每个像素值进行反转,即将像素值v变为255-v。负片变换可以增强图像的对比度,使得暗部变亮,亮部变暗。
示例:对于一个像素值v=100,经过负片变换后的新像素值为255-100=155。
## Thresholding（阈值处理）
定义:阈值处理是指将图像的每个像素值与一个预设的阈值进行比较,根据比较结果将像素值分为两类或多类。常见的阈值处理方法包括全局阈值和局部阈值。
1. 全局阈值:使用一个固定的阈值来处理整个图像。
2. 局部阈值:根据图像的局部特征来动态调整阈值,以适应不同区域的亮度变化。
示例:对于一个像素值v=150,如果全局阈值为100,则经过全局阈值处理后的新像素值为1(表示亮部);如果局部阈值为200,则经过局部阈值处理后的新像素值为0(表示暗部)。
## Basic Intensity Transformations（基本强度变换）
1. 线性变换:将图像的每个像素值进行线性变换,即将像素值v变为a*v+b,其中a和b是常数。
2. 对数变换:将图像的每个像素值进行对数变换,即将像素值v变为c*log(1+v),其中c是一个常数。
3. 伽马变换:将图像的每个像素值进行伽马变换,即将像素值v变为c*(v^gamma),其中c是一个常数,gamma是一个参数。
4. 反转变换:将图像的每个像素值进行反转变换,即将像素值v变为255-v。

示例:对于一个像素值v=100,经过线性变换a=2和b=50后的新像素值为2\*100+50=250;经过对数变换c=10后的新像素值为10\*log(1+100)=10\*log(101);经过伽马变换c=1和gamma=0.5后的新像素值为1*(100^0.5)=10;经过反转变换后的新像素值为255-100=155。

## Contrast Stretching（对比度拉伸）
定义:对比度拉伸是指通过线性变换将图像的像素值范围扩展到整个可用范围,以增强图像的对比度。对比度拉伸可以使得图像中的细节更加明显。

示例:对于一个像素值v=100,如果图像的最小像素值为50,最大像素值为200,则经过对比度拉伸后的新像素值可以通过以下公式计算:

$v' = \frac{v - 50}{200 - 50} * 255$

经过计算,新像素值v'为170。

## Gray Level Slicing（灰度级切片）
定义:灰度级切片是指将图像的像素值分为几个范围,并将每个范围内的像素值映射到一个新的值。灰度级切片可以突出图像中的特定区域或细节。
示例:对于一个像素值v=100,如果将像素值分为三个范围:0-50, 51-150和151-255,并将每个范围内的像素值映射到0, 128和255,则经过灰度级切片后的新像素值为128。

## Bit-plane Slicing（位平面切片）
定义:位平面切片是指将图像的每个像素值分解为二进制位,并将每个位平面单独处理。位平面切片可以突出图像中的特定细节或特征。

示例:对于一个像素值v=100,其二进制表示为01100100,则其位平面切片可以分为以下几个平面:
- 位平面0: 0
- 位平面1: 0
- 位平面2: 1
- 位平面3: 0
- 位平面4: 0
- 位平面5: 1
- 位平面6: 1
- 位平面7: 0
通过处理不同的位平面,可以突出图像中的不同细节或特征。例如,处理位平面0可以突出图像中的最低位细节,而处理位平面7可以突出图像中的最高位细节。

应用场景:位平面切片常用于图像压缩和图像分析中。通过处理不同的位平面,可以实现图像的压缩或提取特定的特征。

## Power-law Transformations（幂律变换）
定义:幂律变换是指将图像的每个像素值进行幂律变换,即将像素值v变为c*(v^gamma),其中c是一个常数,gamma是一个参数。幂律变换可以增强图像的对比度,使得暗部变亮,亮部变暗。

示例:对于一个像素值v=100,经过幂律变换c=1和gamma=0.5后的新像素值为1*(100^0.5)=10;经过幂律变换c=1和gamma=2后的新像素值为1*(100^2)=10000。

应用场景:幂律变换常用于图像增强中,特别是在处理低对比度图像时。通过调整gamma值,可以增强图像中的细节和特征,使得图像更加清晰和易于分析。

## Histogram Equalization（直方图均衡化）
定义:直方图均衡化是指通过对图像的直方图进行均衡化,来增强图像的对比度。直方图均衡化可以使得图像中的像素值分布更加均匀,从而增强图像的细节和特征。

示例:对于一个像素值v=100,如果图像的最小像素值为50,最大像素值为200,则经过直方图均衡化后的新像素值可以通过以下公式计算:
$v' = \frac{v - 50}{200 - 50} * 255$
经过计算,新像素值v'为170。

应用场景:直方图均衡化常用于图像增强中,特别是在处理低对比度图像时。通过均衡化图像的直方图,可以增强图像中的细节和特征,使得图像更加清晰和易于分析。

计算：
1. 计算图像的直方图,得到每个像素值的频率。
2. 计算图像的累积直方图,得到每个像素值的累积频率。
3. 计算图像的均衡化函数,将每个像素值映射到新的像素值。
4. 将图像中的每个像素值替换为新的像素值,得到均衡化后的图像。

累计直方图的计算方法是将每个像素值的频率累加起来,得到每个像素值的累积频率。均衡化函数的计算方法是将每个像素值的累积频率除以图像中像素总数,得到每个像素值的新值。

## Histogram regularization（直方图规范化）
定义:直方图规范化是指通过对图像的直方图进行规范化,来使图像的直方图满足特定的分布。直方图规范化可以增强图像的对比度,使得图像中的细节和特征更加明显。

如何实现:
1. 计算图像的直方图,得到每个像素值的频率。
2. 计算图像的累积直方图,得到每个像素值的累积频率。
3. 计算图像的规范化函数,将每个像素值映射到新的像素值。
4. 将图像中的每个像素值替换为新的像素值,得到规范化后的图像。

规范化函数的计算方法是将每个像素值的累积频率除以图像中像素总数,得到每个像素值的新值。通过调整规范化函数的形状,可以使图像的直方图满足特定的分布,从而增强图像的对比度和细节。

## Histogram matching（直方图匹配）
定义:直方图匹配是指通过对图像的直方图进行匹配,来使图像的直方图与目标直方图相似。直方图匹配可以增强图像的对比度,使得图像中的细节和特征更加明显。

如何实现:
1. 计算输入图像的直方图,得到每个像素值的频率。
2. 计算输入图像的累积直方图,得到每个像素值的累积频率。
3. 计算目标图像的直方图,得到每个像素值的频率。
4. 计算目标图像的累积直方图,得到每个像素值的累积频率。
5. 计算匹配函数,将输入图像的像素值映射到目标图像的像素值。
6. 将输入图像中的每个像素值替换为新的像素值,得到匹配后的图像。

匹配函数的计算方法是将输入图像的累积频率与目标图像的累积频率进行比较,找到最接近的目标像素值,并将输入像素值映射到该目标像素值。通过调整匹配函数的形状,可以使输入图像的直方图与目标图像的直方图相似,从而增强图像的对比度和细节。

## 空间滤波
定义:空间滤波是指通过对图像的每个像素值进行邻域内像素值的加权平均,来增强图像的细节和特征。常见的空间滤波方法包括平滑滤波和锐化滤波。



### Linear filtering（线性滤波）（卷积）
定义:线性滤波是指通过对图像的每个像素值进行邻域内像素值的线性加权平均,来增强图像的细节和特征。常见的线性滤波方法包括均值滤波和高斯滤波。

示例:对于一个像素值v在图像中的位置(x,y),其周围四个已知像素值分别为f(0,0), f(1,0), f(0,1)和f(1,1),则经过均值滤波后的新像素值f(x,y)可以通过以下公式计算:
$f(x,y) = \frac{f(0,0) + f(1,0) + f(0,1) + f(1,1)}{4}$
